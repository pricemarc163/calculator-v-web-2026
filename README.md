## About Calculator

Calculator is a small, no-frills web calculator that runs entirely in the browser. Everything is written in HTML, CSS, and JavaScript, so the project shows how markup, styling, and interaction fit together in one compact front-end example.

It works well as a learning sandbox or a reference point. You can study how basic arithmetic logic is wired up, how a responsive layout is organized, and how simple UI behavior is handled without pulling in a framework.
